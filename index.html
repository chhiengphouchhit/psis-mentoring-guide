💡 រូបមន្តបង្កើតគំនិត និងរឿងនិទាន (Formulas & Story Arc)

រូបមន្ត A (Pain Point to Solution):
Pain Point → Question → Hook → Proof → Solution

ចាប់ផ្តើមពីកង្វល់ជាក់លាក់របស់មាតាបិតា → បង្កើតជាសំណួរ Hook → បង្ហាញសកម្មភាពក្នុងថ្នាក់រៀនជាភស្តុតាង → ផ្តល់ដំណោះស្រាយ។

រូបមន្ត B (Character Transformation in Classroom):
Character → Want → Problem → Action → Change → Meaning

តួអង្គ (សិស្ស/គ្រូ) → បំណងប្រាថ្នា → ឧបសគ្គ/ភាពភ័យខ្លាច → សកម្មភាពអនុវត្ត → ការផ្លាស់ប្តូរ → អត្ថន័យសម្រាប់អនាគត។

រូបមន្ត C (Continuous Improvement Cycle):
Create → Measure → Review → Improve → Repeat

ផលិត → វាស់ទិន្នន័យ (Retention, Shares, Inquiries) → ពិនិត្យ Feedback → កែលម្អ Hook/Pacing ក្នុងវីដេអូបន្ទាប់។

ប្រើប្រាស់ Facebook ច្រើនរាល់ថ្ងៃ តែមិនសូវ Post រូបខ្លួនឯងទេ (Silent Consumer) — ប្រើសម្រាប់ស្រាវជ្រាវ តាមដានព័ត៌មាន និងការអប់រំកូន។

កង្វល់ពិត (Pain Points)

អ្វីដែលមិនចូលចិត្ត (Dislikes)

មិនចូលចិត្តការអួតអាង (Show off), មិនចូលចិត្តការលក់បញ្ចុះតម្លៃខ្លាំងពេក, មិនចូលចិត្តវីដេអូរញ៉េរញ៉ៃគ្មានខ្លឹមសារ។
